# Появление блоков главной

17 ноября 2026 года добавлено лёгкое однократное появление первого экрана и основных секций главной: направлений, информации о компании, партнёров, сертификатов, формы связи, проектов и карты.

На компьютере блок плавно поднимается на 18 px и увеличивает непрозрачность за 560 мс. До 767 px движение сокращается до 10 px, длительность — до 420 мс. Секции начинают появляться непосредственно перед входом в видимую область. При обратной прокрутке анимация не повторяется.

Используется встроенный `IntersectionObserver`, без зависимостей и обработчика прокрутки для анимации. Анимируется отдельное CSS-свойство `translate`, поэтому существующие масштабирование и расположение графики первого экрана сохраняются. Класс удаляется после завершения эффекта. Ожидающие секции не скрываются стилями: без JavaScript, API наблюдения или загруженного CSS текст остаётся видимым.

При `prefers-reduced-motion: reduce` эффект отключён. Включение этой настройки во время анимации сразу показывает содержимое и останавливает последующие эффекты. Клавиатурный фокус также сразу показывает соответствующий блок. При восстановлении страницы из кеша назад/вперёд эффекты останавливаются. На внутренних страницах появление не запускается.

## Установка

Распаковать `downloads/sibel-home-animation-update.zip` в существующую папку проекта рядом с `start-local.cmd`, согласиться на замену файлов, перезапустить сайт и нажать Ctrl+F5.

Архив содержит текущие CSS/JS, предыдущие правки карточек и карты, две иконки и инструкцию. Если эти правки уже установлены, повторная установка сохраняет настройки. База данных и учётные данные в архив не входят.

## Проверка

В Chromium на отдельном стенде с текущими CSS/JS темы проверены ширины 1360, 768, 390 и 320 px, включая сенсорные устройства: все девять элементов первого экрана и секций появляются ровно один раз; длительность и смещение соответствуют ширине; масштабирование графики сохраняется; горизонтального переполнения нет; кнопка заявки и диалог работают.

Отдельно проверены уменьшение движения при загрузке и его переключение во время анимации, немедленная видимость при клавиатурном фокусе, отсутствие JavaScript и IntersectionObserver, внутренние страницы и событие восстановления страницы из кеша. Проверки синтаксиса JS, `git diff --check` и сверка ZIP с исходниками проходят.

Полный WordPress в этой среде не запускался: зависимости Playground отсутствуют и npm недоступен из-за сетевой политики. Проверены непосредственно изменённые CSS/JS и их поведение на стенде; это не повторная проверка всех сценариев WordPress.
