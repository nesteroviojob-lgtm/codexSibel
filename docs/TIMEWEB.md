# Установка на Timeweb

Инструкция относится к обычному хостингу с PHP и MySQL. Требуются PHP **8.1+** (рекомендуется 8.3+), MySQL/MariaDB, HTTPS и установленный WordPress 6.6+. Для приёма файлов нужны стандартные расширения WordPress, для обработки строк — mbstring. Node.js на хостинге не требуется.

## Установка

1. После завершения визуальной проверки собрать тему командой `npm run package`.
2. В панели Timeweb подключить домен, сертификат HTTPS, создать сайт и базу MySQL. Установить актуальный стабильный WordPress через доступный установщик CMS или вручную с wordpress.org.
3. При установке выбрать русский язык и создать собственную учётную запись администратора с уникальным паролем.
4. В WordPress открыть **Внешний вид → Темы → Добавить → Загрузить тему**, выбрать `dist/sibel-theme.zip`, установить и активировать «СИБЭЛ».
5. Открыть **Настройки → Постоянные ссылки**, выбрать «Название записи» и сохранить. Проверить `/products/ktp/` и `/projects/rosneft/`.
6. В **СИБЭЛ · Сайт → Главная и контакты** проверить телефоны, адрес и почту. Заполнить материалы в карточках, загрузить настоящие технические PDF, заполнить и опубликовать юридические страницы.
7. Сделать пробную заявку из незалогиненного браузера и убедиться, что она появилась в панели.

При активации тема один раз создаёт данные из макета. Повторная активация сохраняет пользовательские правки. Не удаляйте опцию `sibel_seed_version`: это маркер первоначального наполнения.

## Почтовые уведомления

Заявки сохраняются в базе независимо от доставки писем. Чтобы получать уведомления, укажите адрес в настройках темы и настройте отправку WordPress через почту домена/SMTP на хостинге. Пароли SMTP задаются в настройках почтового плагина или защищённой конфигурации, а не в файлах темы. Проверьте фактическую доставку тестового письма.

## Перенос наполненного локального сайта

Архив темы переносит код и встроенные исходные изображения. Пользовательские правки, записи и загруженные медиа хранятся в базе и `wp-content/uploads` и требуют отдельного переноса. SQLite локального Playground не нужно копировать как production-базу MySQL.

Для переноса наполнения используйте проверенный инструмент миграции WordPress с поддержкой источника SQLite либо экспорт WordPress **Инструменты → Экспорт** с переносом медиа и настроек отдельно. При замене домена используйте инструмент, который корректно обновляет сериализованные значения WordPress; обычная текстовая замена SQL может повредить данные. Для новой установки тема уже создаёт исходное наполнение из макетов.

## Обслуживание

Резервируйте MySQL и `wp-content/uploads` средствами хостинга. Обновляйте WordPress и установленные плагины. Для ежедневного редактирования создайте отдельного пользователя с ролью **«Менеджер сайта СИБЭЛ»**: он управляет содержимым, но не устанавливает плагины и не редактирует код.
