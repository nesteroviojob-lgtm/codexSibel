# Хедер по новому референсу

Хедер сохраняет фирменные логотипы и оранжевый акцент СИБЭЛ. Компоновка: логотип, пять существующих разделов, телефон, «Оставить заявку» и круглая кнопка поиска.

- В начале главной — прозрачный фон, белые логотип и элементы управления.
- После прокрутки на 24 px — светлая скруглённая панель с лёгкой тенью, оранжевым логотипом и тёмными надписями. При возвращении наверх восстанавливается прозрачное состояние.
- На внутренних страницах, карточках, категориях и юридических страницах — светлая панель сразу. Активный пункт меню выделяется фирменным цветом.
- До 1200 px разделы переходят в выпадающее меню; до 768 px скрывается телефон, до 480 px кнопка сокращается до «Заявка». Полное доступное имя кнопки сохраняется.
- Кнопка заявки открывает существующую форму, поиск — существующий поисковый диалог. Меню закрывается по Escape с возвратом фокуса, клику вне панели, выбору ссылки и переходу к настольной ширине.
- Хедер закреплён при прокрутке; якоря учитывают его высоту, панель администратора WordPress учитывается отдельно.

## Установка локального обновления

1. Закройте окно `start-local.cmd`.
2. Распакуйте содержимое `downloads/sibel-header-update.zip` в существующую папку проекта рядом с `start-local.cmd`, объедините папки и замените файлы.
3. Запустите `start-local.cmd` и обновите сайт через Ctrl+F5.

Архив содержит три изменённых файла темы и обе версии логотипа. Базы данных, настройки, учётные данные и `.runtime` в архив не входят.

## Проверки этой правки

В Chromium проверена компоновка хедера для девяти типов страниц на ширинах 320, 360, 390, 768, 1024, 1199, 1200, 1360, 1920 и 3840 px: элементы не пересекаются, горизонтального переполнения нет. Проверены смена цветов и логотипов при прокрутке и возврате наверх, открытие обоих диалогов, мобильное меню, Escape/фокус, клик вне меню, смена контрольной ширины и подменю WordPress.

Браузерная проверка выполняется на временном стенде с разметкой из актуального `header.php`, настоящими CSS/JS и локальными логотипами темы. Это проверка интерфейса хедера, а не полный запуск WordPress. `node --check` и `git diff --check` проходят. Полные `npm test` / `npm run check` в этой среде не запущены: зависимости WordPress Playground отсутствуют в кеше, а текущая сетевая политика разрешает только Figma. Проверка сохранения заявок и админки не повторялась; серверная обработка не изменялась.
