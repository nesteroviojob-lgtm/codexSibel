# Продолжение работы

## Задача и выбранные решения

Пользователь просит перенести корпоративный сайт СИБЭЛ из Figma с точным совпадением макетов, адаптивной версией и удобной админкой для разделов, товаров и карточек. Последний выбор хостинга — **Timeweb**. Размещение планируется позже, сейчас нужны код и рабочая админка. Используется собственная тема WordPress для обычного PHP-хостинга; платные плагины не нужны.

Пользователь уже запустил сайт и админку **локально на Windows** с Node.js 26.13.0 и вернулся к задаче получения изображений. Запуск — двойной щелчок по `start-local.cmd`, без Node REPL. Состояние WordPress хранится в `.runtime/site`, случайный пароль — в `.runtime/site-credentials.json`; не удалять их при обновлении исходников. Полная визуальная приёмка и production-упаковка по-прежнему требуют оригинальной графики.

## Последние правки: шесть изменений интерактивности

7 ноября 2026 года выполнены шесть уточнений пользователя: проекты выделяются только при наведении/фокусе; стрелка ЩО70 скрыта до наведения/фокуса; партнёры движутся непрерывно на всю ширину окна без стрелки; телефон содержит фиксированный +7 и десять цифр; карты привязаны к конкретной организации; сертификаты в футере открывают собственные изображения.

Пользователь прислал точную ссылку на организацию: **https://yandex.ru/maps/-/CXvjIB38**. Обе карты и кнопки используют её; виджет — `https://yandex.ru/map-widget/v1/-/CXvjIB38?lang=ru_RU`. При первой установке новой версии `sibel_upgrade_organization_map()` однократно меняет сохранённую ссылку на предоставленную пользователем и сохраняет старое значение в `sibel_map_before_organization_update`. Последующие правки администратора не перезаписываются. Внешний Яндекс остаётся заблокированным в среде; содержимое карточки не читалось, источник — ссылка пользователя, ID организации не выдумывался.

Лента состоит из двух одинаковых групп; первая заполняет ширину окна даже на 3840 px. Анимация запускается после декодирования всех изображений, скорость 40 px/s. Учитывается prefers-reduced-motion. Телефон проверяется браузером и сервером, вставка оформленных номеров поддерживается, первая цифра после +7 не теряется. JavaScript версионируется по времени изменения файла для обновления клиентского кеша.

Полные 20 автоматических проверок прошли. Браузерная проверка на 1360/1920/3840/768/390/360 px подтвердила отсутствие горизонтального переполнения, заполнение и движение ленты, загрузку всех её изображений. Проверены наведение/уход курсора, ввод первой 7, буквы, удаление, вставка, ограничение длины, сброс и пять конкретных сертификатов. Наведение эмулировалось как устройство с мышью. Подробности — [INTERACTIONS.md](INTERACTIONS.md).

Текущее обновление для пользователя — `downloads/sibel-interactions-update.zip`: распаковать содержимое в существующую папку рядом с `start-local.cmd`, заменить файлы, перезапустить, Ctrl+F5. В комплекте предыдущие правки, без базы или секретов. Все файлы темы и обе прежние фотографии включены; остальные оригиналы уже установлены пользователем. ## Последние правки: контакты, карты и юридические документы

- `inc/contacts.php`: отдельные `tel:` для обоих номеров, нормализация шестизначного томского телефона по коду основного номера, кликабельные контакты заявок. Карты заменены на iframe Яндекса с поиском адреса из настроек; кнопки открытия ведут на тот же адрес, API-ключ не требуется.
- `inc/legal.php`, `page-legal.php`, `legal/*.html`: политика и отдельное согласие, доступный в редакторе шаблон страницы и пункт «Юридические документы». На локальной версии шаблоны опубликованы для просмотра; на новом production-сервере создаются черновиками для заполнения заказчиком. Миграция заполняет пустые прежние страницы и не трогает отредактированные тексты или настройки. Пустой legacy-черновик `terms` переиспользуется как `consent`.

- `npm test`: все 17 проверок прошли. `npm run check`: синтаксис 17 PHP-файлов, JavaScript и все 76 изображений проверены. Упаковка проходит. На компьютере пользователя изменения применяются распаковкой `downloads/sibel-contacts-legal-update.zip` в существующую папку рядом со `start-local.cmd`, затем перезапуском и Ctrl+F5. В архиве нет `.runtime`, настроек или секретов.

Сеть среды не разрешает Яндекс: живая загрузка iframe здесь не проверялась, для браузерной проверки компоновки запросы Яндекса блокируются явно. Нужна проверка внешней карты на компьютере пользователя. Подробные инструкции и источники по шаблонам — [LEGAL.md](LEGAL.md). ## Текущее состояние

**Последняя проблема локального просмотра:** пользователь сообщил, что оборудование на первом экране не появилось; прямая ссылка `http://127.0.0.1:9400/wp-content/themes/sibel/assets/images/d9626.png?check=20261106` у него дала ошибку или пустую страницу (конкретный HTTP-статус не сообщён). В опубликованном архиве файл присутствует и совпадает с оригиналом. Причина на компьютере пользователя окончательно не установлена.

Подготовлен `downloads/sibel-home-photo-fix.zip` (около 715 КБ): три плоских файла `fix-home-photo.cmd`, `repair-home-photo.mjs`, `d9626.png`. Пользователь распаковывает их в существующую папку рядом со `start-local.cmd` и запускает `fix-home-photo`. Скрипт проверяет наличие установленного сайта `.runtime/site/wp-load.php`, требует закрыть прежний сервер на 9400, проверяет SHA256 оригинала, копирует фото в папку темы, меняет только `sibel_settings.hero_image` через реальный WordPress и запускает `start-local` из этой же папки. Сохраняются первый прежний выбор в `sibel_hero_before_repair` и прежние байты файла, если он отличался. Два целевых теста проверяют копирование/резервную копию/отказ при неверном PNG и сохранность остальных настроек WordPress при повторном запуске. Исходник — `scripts/repair-home-photo.mjs`; в архиве он лежит в корне для простого запуска.

Рабочая ветка — `codex/sibel-figma` в репозитории `nesteroviojob-lgtm/codexSibel`. Пользователь явно разрешил публикацию полного исходного кода в этом публичном репозитории.
