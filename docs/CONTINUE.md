# Продолжение работы

## Задача и выбранные решения

Пользователь просит перенести корпоративный сайт СИБЭЛ из Figma с точным совпадением макетов, адаптивной версией и удобной админкой для разделов, товаров и карточек. Последний выбор хостинга — **Timeweb**. Размещение планируется позже, сейчас нужны код и рабочая админка. Используется собственная тема WordPress для обычного PHP-хостинга; платные плагины не нужны.

Пользователь уже запустил сайт и админку **локально на Windows** с Node.js 26.13.0 и вернулся к задаче получения изображений. Запуск — двойной щелчок по `start-local.cmd`, без Node REPL. Состояние WordPress хранится в `.runtime/site`, случайный пароль — в `.runtime/site-credentials.json`; не удалять их при обновлении исходников. Полная визуальная приёмка и production-упаковка по-прежнему требуют оригинальной графики.

## Последние правки: контакты, карты и юридические документы

6 ноября 2026 года пользователь попросил кликабельные телефоны/почту, настоящие Яндекс Карты с меткой по текущему адресу, две редактируемые юридические страницы и обязательный чекбокс со ссылками в форме. Выполнено:

- `inc/contacts.php`: отдельные `tel:` для обоих номеров, нормализация шестизначного томского телефона по коду основного номера, кликабельные контакты заявок. Карты заменены на iframe Яндекса с поиском адреса из настроек; кнопки открытия ведут на тот же адрес, API-ключ не требуется.
- `inc/legal.php`, `page-legal.php`, `legal/*.html`: политика и отдельное согласие, доступный в редакторе шаблон страницы и пункт «Юридические документы». На локальной версии шаблоны опубликованы для просмотра; на новом production-сервере создаются черновиками для заполнения заказчиком. Миграция заполняет пустые прежние страницы и не трогает отредактированные тексты или настройки. Пустой legacy-черновик `terms` переиспользуется как `consent`.
- В каждой форме отдельный обязательный чекбокс без предустановленной галочки, ссылки на `/consent/` и `/privacy/` открываются отдельно. В заявке сохраняются время, ссылка, снимок текста согласия и версия. Неподтверждённые заявки отклоняются сервером.
- `npm test`: все 17 проверок прошли. `npm run check`: синтаксис 17 PHP-файлов, JavaScript и все 76 изображений проверены. Упаковка проходит. На компьютере пользователя изменения применяются распаковкой `downloads/sibel-contacts-legal-update.zip` в существующую папку рядом со `start-local.cmd`, затем перезапуском и Ctrl+F5. В архиве нет `.runtime`, настроек или секретов.

Сеть среды не разрешает Яндекс: живая загрузка iframe здесь не проверялась, для браузерной проверки компоновки запросы Яндекса блокируются явно. Нужна проверка внешней карты на компьютере пользователя. Подробные инструкции и источники по шаблонам — [LEGAL.md](LEGAL.md). Полная визуальная приёмка всего сайта по-прежнему не завершена, PR остаётся черновиком.

**Все 76 изображений получены.** Из `SIBEL-FIGMA-1.zip` и `SIBEL-FIGMA-2.zip` добавлены 75 оригиналов с именами из манифеста; CRC и заголовки PNG/SVG проверены, байты не менялись. В CSS для фотографии используется `cover` в пределах блока: прежнее увеличение и смещение исходного фото к этому готовому кадру не применяются.

Фото оборудования первого экрана — `d9626.png`. Для изображений и CSS добавлены версии по времени изменения файлов, локальный сервер возвращает `Cache-Control: no-store`. Пустые поля `hero_image` и `company_image` используют предоставленные фотографии; URL, выбранные администратором, сохраняются. Идентификатор кадрирования миниатюр проекта определяется по пути URL без параметров версии.

**Обновление на компьютере пользователя:** локальный сайт сам не получает изменения из GitHub. Закрыть окно запуска, распаковать содержимое `downloads/sibel-home-image-update.zip` в существующую папку рядом с `start-local.cmd`, объединить папки и заменить совпадающие файлы, перезапустить `start-local.cmd` и нажать Ctrl+F5. Архив содержит оба фото, изменённые PHP/CSS и локальный сервер, без базы, настроек и секретов. Если пользователь ранее выбрал другие фотографии в админке, заменить их через «Главная и контакты»; не сбрасывать все настройки или `.runtime`.

Чтение источника через `use_figma` также отклонено из-за лимита Starter. Пока лимит не изменится, повторять запросы не нужно. Пользовательское фото не воссоздавать и не подменять.

Сохраняется `download-images.cmd` и Node/curl-загрузчик `scripts/download-assets.mjs`: повторный запуск пропускает полученные файлы и собирает `SIBEL-FIGMA.zip` (или нумерованные архивы по ~20 MiB). Это передача пользователем файлов, доступных ему; облачная среда не обращается к запрещённому хосту.

Небольшой архив обновления `downloads/sibel-figma-download.zip` содержит только загрузчик, манифест и инструкцию. Распаковать в существующую папку проекта рядом со `start-local.cmd`. Для работы нужен уже установленный `node_modules/fflate` (есть после запуска сайта). Архив не включает runtime, базу или учётные данные. При изменении загрузчика/манифеста пересобрать этот архив.

Загрузчик проверен тремя тестами на локальном HTTP-сервере: неизменность байтов и содержимого ZIP, повторная загрузка из кеша, отказ при HTML/HTTP 410, очистка временных файлов и валидация манифеста. Все 76 ссылок в этой среде не проверялись; временные URL могут истечь. `npm test`: 14 проверок прошли; проверяется выбор обеих фотографий администратором и возврат к предоставленным файлам при пустых значениях на главной и /about/. Полные `npm run check` и `npm run package` прошли, архив темы — `dist/sibel-theme.zip`.

Исправлены найденные по данным слоёв расхождения формы и геометрии, устранено горизонтальное переполнение. Ранее все семь страниц проверены на 1360/1440/1024/768/390/360 px без графики. Подробный отчёт: [VISUAL-AUDIT.md](VISUAL-AUDIT.md). Теперь все изображения получены, техническая упаковка проходит. Полная визуальная приёмка семи страниц ещё не выполнена, PR остаётся черновиком.

Осталось до завершения полной визуальной приёмки:

1. Прочитать `figma:figma-design-to-code`, создать новую Figma-сессию для этой задачи и получить дизайн-контекст со скриншотами. Узлы перечислены в DESIGN.md.

Временные ссылки Figma могут истечь; при необходимости обновлять через доступный коннектор. Не заменять существующие пользовательские изображения автоматически.
3. `npm ci`, `npm run dev`. В среде нужны разрешения на локальный сервер. Превью основано на PHP WASM; первый запуск подготавливает официальный WordPress из GitHub. Production использует обычные PHP и MySQL.
4. Сделать визуальную сверку всех семи страниц в ширине 1360 px и адаптивные проверки 1440/1024/768/390/360 px. Проверить геометрию каждого изображения и SVG, кадрирование, шрифты, отступы, меню, диалоги и формы. Публичная вёрстка пока НЕ прошла визуальную приёмку: проверять её без оригинальной графики недостаточно.
5. `npm run check`, `npm test`, `npm run package`. Текущая упаковка проходит; её успешность не подтверждает полную визуальную приёмку.
6. Обновить статус README и PR после реальной визуальной проверки. Пользователь не просил публиковать сайт сейчас: перенос на Timeweb — будущий шаг.
