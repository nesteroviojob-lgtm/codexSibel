# СИБЭЛ — корпоративный сайт

Собственная тема WordPress по макетам Figma, адаптивная вёрстка и панель управления содержимым. Целевой хостинг — **Timeweb, обычный PHP-хостинг с MySQL**. Node.js нужен только для локальной разработки и проверок.

**Статус: работающая версия кода, визуальная приёмка ещё не завершена.** В исходной облачной среде заблокирован домен загрузки Figma. Все страницы и админка реализованы, оригинальные шрифты Vela Sans сохранены локально; 76 графических файлов пока необходимо скачать. `npm run check` и упаковка намеренно завершаются ошибкой до получения оригинальной графики. Не публикуйте эту версию как готовый сайт.

## Что реализовано

- Главная, каталог, карточка товара, сертификаты, проекты, страница проекта и контакты.
- Адаптивные сетки, мобильное меню, поиск, галереи и просмотр документов.
- Русская панель «СИБЭЛ · Сайт»: обзор, товары, разделы каталога, проекты, сертификаты, партнёры и заявки.
- Настройки текстов главной, изображений, контактов, названий и видимости разделов.
- Изменение заголовков, описаний, характеристик, PDF, галерей, порядка и статуса публикации карточек.
- Стандартные учётные записи WordPress и ограниченная роль «Менеджер сайта СИБЭЛ».
- Заявки сохраняются в базе, имеют статусы «Новая», «В работе», «Обработана». Уведомления по почте включаются отдельной настройкой.

## Запуск для разработки

Требуются Node.js 24.18+, npm 11.16+, Python 3 и curl. В production эти инструменты не нужны.

```bash
npm ci
npm run assets
npm run dev
```

Сайт: `http://127.0.0.1:9400/`. Панель: `http://127.0.0.1:9400/wp-admin/admin.php?page=sibel`.

Локальный WordPress запускается через официальный WordPress Playground с SQLite. Состояние хранится в `.runtime/site`, случайный пароль локального администратора — в `.runtime/site-credentials.json`. Эти файлы исключены из Git и архива темы. Не используйте локальные учётные данные для production. При первом запуске скачивается WordPress 6.9 из официального зеркала `WordPress/WordPress` на GitHub. Сервер слушает только `127.0.0.1`.

## Проверки и сборка

```bash
npm run check
npm test
npm run package
```

Проверки охватывают синтаксис PHP/JS, отсутствие временных Figma URL в исполняемом коде, наличие оригинальной графики, создание и повторную инициализацию данных, все семь страниц, вход в панель, сохранение настроек, черновики, защиту полей и приём заявок.

`node scripts/check.mjs --code-only` позволяет отдельно проверить код при заблокированной загрузке графики; это **не** подтверждение готовности сайта.

После успешной сборки архив темы появится в `dist/sibel-theme.zip`.
