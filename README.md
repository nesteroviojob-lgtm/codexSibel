# СИБЭЛ — корпоративный сайт

Собственная тема WordPress по макетам Figma, адаптивная вёрстка и панель управления содержимым. Целевой хостинг — **Timeweb, обычный PHP-хостинг с MySQL**. Node.js нужен только для локальной разработки и проверок.

**Статус: визуальная приёмка ещё не завершена.** Все 76 изображений находятся в проекте: 75 оригинальных PNG/SVG из архивов Figma и предоставленная пользователем фотография производства `5c50a.png` (610 × 582), сохранённая без изменения байтов. Фото первого экрана и блока «О компании» подключены. Пустые поля используют исходные изображения; выбранные администратором фотографии сохраняются. Версии изображений и CSS обновляются при изменении файлов, локальный сервер отключает кеширование. Полная проверка кода, файлов и упаковка темы проходят. Визуальная сверка всех семи экранов ещё не завершена; детали — [docs/VISUAL-AUDIT.md](docs/VISUAL-AUDIT.md).

## Что реализовано

- Главная, каталог, карточка товара, сертификаты, проекты, страница проекта и контакты.
- Адаптивные сетки, мобильное меню, поиск, галереи и просмотр документов.
- Русская панель «СИБЭЛ · Сайт»: обзор, товары, разделы каталога, проекты, сертификаты, партнёры и заявки.
- Настройки текстов главной, изображений, контактов, названий и видимости разделов.
- Изменение заголовков, описаний, характеристик, PDF, галерей, порядка и статуса публикации карточек.
- Стандартные учётные записи WordPress и ограниченная роль «Менеджер сайта СИБЭЛ».
- Заявки сохраняются в базе, имеют статусы «Новая», «В работе», «Обработана». Уведомления по почте включаются отдельной настройкой.
- Отдельные кликабельные телефоны и почта; Яндекс Карты на главной и в контактах используют ссылку организации из настроек.
- Раздел «Юридические документы», редактируемые шаблоны политики и согласия, отдельный обязательный чекбокс в формах со ссылками на оба документа.
- Состояния карточек при наведении, непрерывная лента партнёров на всю ширину окна, ввод телефона после фиксированного `+7` и открытие конкретных сертификатов из футера.

## Запуск для разработки

Для локального просмотра нужны Node.js 24.18+ и npm (поставляется вместе с Node.js; рекомендуемая версия 11.16+). PHP, MySQL, Python и Docker отдельно устанавливать не нужно. В production Node.js не требуется.

На **Windows** распакуйте проект и дважды щёлкните **`start-local.cmd`**. При первом запуске он установит зависимости и скачает WordPress, затем откроет сайт и админку в браузере. Логин и случайный локальный пароль появятся в окне запуска. Оставьте это окно открытым на время просмотра. Если Node.js ещё не установлен, скачайте его с https://nodejs.org/ и после установки повторно откройте файл.

Запуск из терминала на любой системе:

```bash
npm ci
npm run dev
```

Сайт: `http://127.0.0.1:9400/`. Панель: `http://127.0.0.1:9400/wp-admin/admin.php?page=sibel`.

Локальный WordPress запускается через официальный WordPress Playground с SQLite. Состояние хранится в `.runtime/site`, случайный пароль локального администратора — в `.runtime/site-credentials.json`. Эти файлы исключены из Git и архива темы. Не используйте локальные учётные данные для production. При первом запуске Node.js скачивает WordPress 6.9 из официального зеркала `WordPress/WordPress` на GitHub. Сервер слушает только `127.0.0.1`.

Просмотр работает **без отсутствующей графики**; команда `npm run assets` не нужна для запуска.

Если фото первого экрана не появилось после обновления, распакуйте `downloads/sibel-home-photo-fix.zip` в существующую папку рядом со `start-local.cmd` и запустите **`fix-home-photo.cmd`**. Закройте прежнее окно запуска сайта. Фиксер проверит оригинальный PNG, установит его в папку темы, выберет его в настройках WordPress и запустит сайт из этой же папки. Прежний выбор фото сохраняется в локальной резервной копии; остальные настройки сайта сохраняются. Архив содержит три файла, которые нужно распаковать вместе.

## Загрузка изображений из Figma

После первого запуска сайта на Windows дважды щёлкните **`download-images.cmd`** рядом с `start-local.cmd`. Он скачает оригинальные PNG/SVG из сохранённого манифеста в `wordpress/wp-content/themes/sibel/assets/images/`. Затем обновите страницу локального сайта клавишей F5.

В корне проекта появится **`SIBEL-FIGMA.zip`** (при большом объёме — несколько нумерованных архивов). Прикрепите эти архивы в чат для переноса оригиналов в рабочую среду и визуальной сверки. Архивы содержат только графику. Повторный запуск пропускает уже полученные изображения; HTML-страницы ошибок не сохраняются вместо изображений.

На других системах: `npm run assets`. Нужны Node.js и curl; Python для загрузки графики не требуется. Ссылки Figma временные: если они истекли или требуют входа, их нужно обновить через Figma-коннектор. Для упаковки production-темы через `npm run package` нужен Python 3.

## Проверки и сборка

```bash
npm run check
npm test
npm run package
```

Проверки охватывают синтаксис PHP/JS, отсутствие временных Figma URL в исполняемом коде, наличие оригинальной графики, создание и повторную инициализацию данных, все семь страниц, вход в панель, сохранение настроек, черновики, защиту полей и приём заявок.

`node scripts/check.mjs --code-only` позволяет отдельно проверить код при заблокированной загрузке графики; это **не** подтверждение готовности сайта.

После успешной сборки архив темы появится в `dist/sibel-theme.zip`.
